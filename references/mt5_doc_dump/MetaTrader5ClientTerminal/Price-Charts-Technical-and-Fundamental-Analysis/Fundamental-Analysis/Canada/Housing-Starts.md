# Housing Starts

Indicator showing the number of buildings that appear each month. The [start of construction](https://www.mql5.com/en/economic-calendar/canada/cmhc-housing-starts) is considered to be laying the foundation for future building. The index is a leading indicator of economic activity in the construction sector.

  * Release Frequency: monthly.
  * Release Schedule: 08:15 EST, a week after the reference month.
  * Source: Statistics Canada.
