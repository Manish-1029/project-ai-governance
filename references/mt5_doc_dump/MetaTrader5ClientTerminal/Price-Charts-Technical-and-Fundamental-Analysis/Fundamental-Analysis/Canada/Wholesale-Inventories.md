# Wholesale Inventories

The indicator reflects the dynamics of changes in inventories at the warehouses. The measure of wholesale inventories is based on the data on [wholesale sales](https://www.mql5.com/en/economic-calendar/canada/wholesale-trade-mm).

  * Release Frequency: monthly.
  * Release Schedule: 08:30 EST.
  * Source: Statistics Canada.
