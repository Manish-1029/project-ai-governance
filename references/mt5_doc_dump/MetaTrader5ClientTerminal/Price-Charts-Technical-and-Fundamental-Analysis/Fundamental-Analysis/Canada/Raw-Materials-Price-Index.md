# Raw Materials Price Index

This is a composite indicator that measures [price changes for raw materials](https://www.mql5.com/en/economic-calendar/canada/rmpi-mm) purchased by industries. The indicator monitors the inflation component, and it can be used as a leading indicator of future production costs, as well as to predict the dynamics of growth in the industry and increase/decrease of [PPI](Producer-Price-Index.md).

  * Release Frequency: monthly.
  * Release Schedule: 08:30 EST.
  * Source: Statistics Canada.
