# Help-Wanted Index

Help-Wanted Index characterizes the volume of published advertisements in newspapers on hiring employees. 1987 is considered as the base, it's value is "100". [Moving Averages](../../Technical-Indicators/Trend-Indicators/Moving-Average.md) are used for index analysis. If the moving average shows the index trend change over several months, it can be a sign of the changing situation on the labor market. Also, the index can give an idea about a possible change of the economic situation in different regions of the country. 

It has almost no effect on the market. The influence of the index is limited, because only a limited number of major regional newspapers is taken into account.

  * Release Frequency: monthly.
  * Release Schedule: 10:00 EST, the last Thursday of the month.
  * Source: Conference Board.
