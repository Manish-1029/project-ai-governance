# Westpac-Melbourne Institute Coincident Index

The indicator reflects the current economic activity in Australia. It is a generalized indicator of the index of leading indicators and a measure of sustainable economic development of the country.

  * Release Frequency: monthly.
  * Source: Westpac-Melbourne Institute Survey of Consumer Sentiment.
