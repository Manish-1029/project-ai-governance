# Producer Output Prices (PPI Output)

This indicator is defined as the change in the level of manufacturer's selling prices in the industry. It is a string indicator of inflation. It reflects inflationary pressures on the economy from the side of manufacturers. It has a significant impact on the market.

  * Release Frequency: quarterly.
  * Release Schedule: 22:45 GMT.
  * Source: Statistics New Zealand.
