# Shapes

Various shapes can be applied to a price or indicator chart using the "Objects — Shapes" items of the ["Insert"](../../Getting-Started/User-Interface.md) menu or the ["Line Studies"](../../Getting-Started/User-Interface.md) toolbar. Shapes serve to highlight important areas in a chart. The following shapes are available in the platform:

| Type | Description  
![Rectangle](images/rectangle_icon.png) | Rectangle | To draw the figure two points must be defined. [Read more...](Shapes/Rectangle.md)  
![Triangle](images/triangle_icon.png) | Triangle | To draw the figure three points must be defined. [Read more...](Shapes/Triangle.md)  
![Ellipse](images/ellipse_icon.png) | Ellipse | To draw the figure three points must be defined. [Read more...](Shapes/Ellipse.md)
