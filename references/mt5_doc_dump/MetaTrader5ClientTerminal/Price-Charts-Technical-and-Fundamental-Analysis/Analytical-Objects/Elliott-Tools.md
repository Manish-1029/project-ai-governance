# Elliott Tools

Elliott tools can be applied to a price or indicator chart using the "Objects — Elliott" items of the ["Insert"](../../Getting-Started/User-Interface.md) menu or the ["Line Studies"](../../Getting-Started/User-Interface.md) toolbar. 

Two types of Elliott tools for displaying waves are available in the platform: 

| Type | Description  
![Impulse Wave](images/elliott_motive_wave_icon.png) | Impulse Wave | According to Elliott's theory, impulse waves create a directed trend (bull or bear) and cause the market to move very actively. Five points are necessary to draw this tool.  
![Elliott Correction Wave](images/elliott_corrective_wave_icon.png) | Elliott Correction Wave | Corrective waves (rollbacks) are characterized by moving against the trend.  
  
Section ["Elliott Wave Theory"](Elliott-Tools/Elliott-Wave-Theory.md) features theoretical aspect of working with these objects. Practical details are described in section ["Construction of waves"](Elliott-Tools/Construction-of-Waves.md).
