# Arrows

Various shapes can be applied to a price or indicator chart using the "Objects — Arrows" items of the [Insert](../../Getting-Started/User-Interface.md) menu or the button ![Arrows](images/arrows_icon.png) in the [Line Studies](../../Getting-Started/User-Interface.md) toolbar. The following objects are described in this section:

| Type | Description  
![Thumbs Up](images/thumbs_up_icon.png) | Thumbs Up | The "Thumbs Up" sign anchored to a certain point in a chart.  
![Thumbs Down](images/thumbs_down_icon.png) | Thumbs Down | The "Thumbs Down" sign anchored to a certain point in a chart.  
![Up Arrow](images/arrow_up_icon.png) | Up Arrow | The "Arrow Up" sign anchored to a certain point in a chart.  
![Down Arrow](images/arrow_down_icon.png) | Down Arrow | The "Arrow Down" sign anchored to a certain point in a chart.  
![Stop Sign](images/stop_sign_icon.png) | Stop Sign | The "Stop Sign" anchored to a certain point in a chart.  
![Check Sign](images/check_sign_button.png) | Check Sign | The "Check Sign" anchored to a certain point in a chart.  
![Left Price Label](images/left_price_label_icon.png) | Left Price Label | The "Left Price Label" shows the price value left to the point selected in the chart.  
![Right Price Label](images/right_price_label_icon.png) | Right Price Label | The "Right Price Label" shows the price value right to the point selected in the chart.  
![Buy Sign](images/buy_sign_icon.png) | Buy Sign | The "Buy sign" is intended for marking Buy deals, it is anchored to a certain point in a chart.  
![Sell Sign](images/sell_sign_icon.png) | Sell Sign | The "Sell sign" is intended for marking Sell deals, it is anchored to a certain point in a chart.  
![Arrow](images/arrows_icon_1.png) | Arrow | Placing of any available sign according to a user's choice.  
  
To draw these objects, one should select one of them and click on the necessary place of a chart.

## Parameters

All objects of this group have identical parameters, except for price labels that do not have the anchor angle.

![Parameters](images/arrow_parameters.png)

  * Date/Value — coordinates of the anchor point of the object (date/value of the price scale);
  * Arrow Type — one of object types specified in the table above. When selecting "Other", an additional "Symbol" field appears to the right of this field;
  * Anchor — one of object sides (top or bottom) on which the point of anchoring the object to a chart or window is located. This parameter is not used for price labels..
  * Symbol — this field appears only when "Other" is selected as the arrow type. A click on ![Browse](images/browse_button.png) opens a window with available symbols. To select one a double-click on an icon is used.



Common parameters of object are described in a [separate section (#draw-settings)](../Analytical-Objects.md#draw-settings).
