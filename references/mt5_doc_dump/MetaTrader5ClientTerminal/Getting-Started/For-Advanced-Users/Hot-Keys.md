# Key Shortcuts

Keyboard shortcuts (also referred to as hotkeys) are keys and their combinations that allow to execute various commands fast and without using menus or toolbars. Keyboard shortcuts can be assigned for calling any element of the [Navigator](../User-Interface.md) window, except for elements of the [Accounts](Manage-Trading-Accounts.md) group. In order to assign a combination of keys to an element, the "![Set hotkey](images/set_hotkey_icon.png) Set hotkey" command of its context menu should be executed.

> Assigned hotkeys are of higher priorities than predefined ones. For example, initially the "Ctrl+O" combination calls the [platform setup](../Platform-Settings.md) window. If call of the ["On Balance Volume"](../../Price-Charts-Technical-and-Fundamental-Analysis/Technical-Indicators/Volume-Indicators/On-Balance-Volume.md) indicator is set to the same combination, "Ctrl+O" will not call the platform setup window any more.

Predefined keyboard shortcuts execute various functions depending on what platform interface window is currently active. Some hotkeys execute certain functions independent of focus.

## Keyboard shortcuts in the [Chart](../../Price-Charts-Technical-and-Fundamental-Analysis/View-and-Configure-Charts.md) Window

Hotkeys | Description  
---|---  
![Left Arrow](images/arrow_left_icon.png) | Scroll [chart](../../Price-Charts-Technical-and-Fundamental-Analysis/View-and-Configure-Charts.md) to the left.  
![Right Arrow](images/arrow_right_icon.png) | Scroll chart to the right.  
![Up Arrow](images/arrow_up_icon.png) | Fast chart scroll to the left; in case of a [fixed scale (#fixed-scale)](../../Price-Charts-Technical-and-Fundamental-Analysis/Additional-Features/Chart-Settings.md#fixed-scale) — chart scroll upwards.  
![Down Arrow](images/arrow_down_icon.png) | Fast chart scroll to the right; in case of a fixed scale — chart scroll downwards.  
NumPad 5 | Restoring of automatic chart vertical [scale (#vetical-scale)](../../Price-Charts-Technical-and-Fundamental-Analysis/Additional-Features/Chart-Management.md#vetical-scale) after its being changed. If the scale was defined, this hot key will return the chart into the visible range.  
Page Up | Fast chart scroll to the left.  
Page Down | Fast chart scroll to the right.  
Home | Move chart to the start point.  
End | Move chart to the end point.  
"-" | Zoom out chart.  
"+" | Zoom in chart.  
Delete | Delete all selected graphical [objects](../../Price-Charts-Technical-and-Fundamental-Analysis/Analytical-Objects.md).  
Backspace | Delete the latest objects imposed to a chart.  
Enter | Open/close [fast navigation bar](../User-Interface.md).

## Common Actions in the Platform

Hotkeys | Description  
---|---  
Esc | Close dialog windows.  
F1 | Open the "Userguide"  
F3 | Open the ["Global variables"](../../Algorithmic-Trading-Trading-Robots/Global-Variables.md) window.

F10 | Open "Quotes Window".  
F11 | Enable/disable fullscreen mode. The fullscreen mode hides all platform windows except the chart. If you have manually opened additional windows, when you exit and re-enter the fullscreen mode, they will be hidden again while your changes will not be saved.  
Alt+F4 | Close the platform.  
Ctrl+C or Ctrl+Insert | Copy to clipboard.  
Ctrl+D | Open/close the ["Data Window" (#datawindow)](../../Price-Charts-Technical-and-Fundamental-Analysis/View-and-Configure-Charts.md#datawindow).  
Ctrl+E | Allow/prohibit [use of Expert Advisors](../../Algorithmic-Trading-Trading-Robots/Expert-Advisors-and-Custom-Indicators.md).  
Ctrl+M | Open/close the ["Market Watch"](../../Trading-Operations/Market-Watch.md) window.  
Ctrl+N | Open/close the ["Navigator"](../User-Interface.md) window.  
Ctrl+O | Open the ["Settings"](../Platform-Settings.md) window.  
Ctrl+R | Open/close the "Tester" window.  
Ctrl+T | Open/close the ["Toolbox"](../User-Interface.md) window.  
Ctrl+F9 | Open the ["Trade" (#position-open)](../../Trading-Operations/Executing-Trades.md#position-open) tab in the "Toolbox" window and switch the control focus to it. After that trade activities can be managed using the keyboard.
